# 冷门判断 DE1-UPSET-RULES-0.1

清晰热门：去水欧赔的主胜或客胜概率至少0.45，且领先其余最大项至少0.10；缺赔率则按泊松基线辨识，标记模型口径。无明确热门时不强行判断。输出分别保留热门不胜概率（含平局）和弱队获胜概率，二者均来自基础模型，不能与规则分数混用。

| 信号 | 规则分 | 要求 |
|---|---:|---|
| 热门欧赔去水概率下跌至少0.03 | 20 | 同一机构的两条有时间戳快照，间隔不超过7天 |
| 热门亚盘让步减弱至少0.25球 | 20 | 同机构、统一主队让球符号；价格仅记录不代替让球线 |
| 市场热门概率高于模型至少0.08 | 15 | 有可用市场快照，归并市场信号族 |
| 热门真实资金占比比去水概率高至少0.15 | 20 | 同一市场场所、明确时间窗/币种/总金额，资金和赔率快照差不超过1小时 |
| 热门重大负面或弱队重大正面球队/阵容资讯 | 20 | 明确球队、方向、重要程度、原始来源 |
| 经核验的赛程/战意等情境 | 20 | 相同结构，单列情境族，不自动从叙述猜权重 |

同族取最高分，反向证据每族扣10分，总分限制0–100。欧亚盘及模型市场差异归并一族；新闻与阵容归并球队一族；同一来源文章的旧版本替换为最新断言。至少三种可用维度、三个信号族且分数至少50才标记研究高风险；分数至少20为关注。证据少于三维度输出信息不足，而非低风险。相反方向赔率或重大资讯保留为反证。

所有证据同时满足发布时间和首次采集时间不晚于截止，trust至少0.7；欧赔/亚赔/阵容24小时，资金12小时，新闻/情境168小时内。缺失、过时、低可信度不能当零风险。trust是采集审核评级，不是模型学得权重；人工输入需核实原文，代码不会证明文章真伪。

资金拥挤可能提示脆弱性，不证明操盘、假球或必然冷门。没有成交量/投注金额来源时缺失资金维度；赔率波动本身不提供真实资金。此处全部阈值为未校准研究规则，需带时间戳多源数据前瞻验证，不代表概率或收益保证。
