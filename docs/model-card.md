# 独立德甲模型 DE1-POISSON-0.1

这是研究版，当前不宣称超过市场或达到 WINNER12 宣传准确率。

输入仅为德甲真实历史赛果，学习球队进攻、对手防守及联赛主客进球均值。采用带收缩的泊松似然、最近四年窗口与540天半衰期；回溯线搜索保证训练目标单调下降。参数在回测前固定，没有用测试段挑参数。未知球队回落到德甲均值并明确标记；新增赛事别名必须核实后配置，不做模糊匹配。

训练文件 `models/poisson-v0.1.json` 记录参数、训练场数、日期截止、来源可得时间、训练标签摘要哈希和优化检查。当前模型按2026-10-13截止学习了1188场近四年的赛事，包含当前赛季已完赛赛果。输出胜平负、预期进球及前三比分；独立泊松未建低比分相关性、过程xG或时间变化模型。

## 评估

`reports/backtest/backtest.json`、`predictions.jsonl` 给出每场预测、训练标签哈希、真实结果及全部分母。2022/23验证306场；2023/24–2025/26测试918场，每季用开赛前历史拟合并整季冻结，下一季允许学习已结束赛季。当前未完赛季单列排除。

测试三分类胜平负453/918（49.35%）；第一比分104/918（11.33%）；LogLoss 1.00833，三分类Brier采用三项误差平方之和，0.60160。完整可靠性分箱保留在JSON。历史频率基线与回顾性赔率基线也分别保留；模型不能据此宣称优于市场。

对明确热门场次，另评估热门不胜（含平局）与弱队获胜的二元Brier，分别保留分母。它们是泊松概率检验，**不是冷门规则准确率**。历史赔率没有逐条发布时间，仅作单独回顾性对照，不能用于严格赛前特征。所有历史重建都使用今天下载的真实赛果，不冒充当年冻结预测。

## 尚未验证

五个外部LLM服务没有在本次环境实际鉴权调用；已完成失败/响应校验和真实双轮传递的模拟接口测试。默认是五角色本地证据审计，外部调用数为零，不把角色函数称作五个真实外部大模型。

阵容、新闻、赛程与资金只进入证据审阅和冷门规则，不存在已学成的定性权重。历史资金、阵容及带时间戳市场变动数据不全，冷门分数和外部共识都未校准、未验证命中率。应持续收集赛前冻结快照后另设前瞻验证段，保留拒答及无信号场次，报告覆盖率、Brier、冷门召回及误报率。
